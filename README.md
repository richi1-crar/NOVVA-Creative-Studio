# NOVVA — sitio web de marketing digital

## Archivos
- `index.html`: página principal.
- `quienes-somos.html`: presentación del estudio.
- `servicios.html`: servicios y metodología.
- `referencias.html`: caso conceptual de marca de moda.
- `contacto.html`: formulario que prepara un correo.
- `css/style.css`: estilos responsive.
- `js/main.js`: menú móvil y lógica del formulario.
- `assets/logo-novva.jpeg`: logo original proporcionado.

## Ejecutar localmente
Abre la carpeta en Visual Studio Code y abre `index.html` con Live Server o directamente en el navegador.

## Personalizar antes de publicar
1. En `js/main.js`, reemplaza `contacto@novva.co` por el correo real.
2. Cambia las fotografías de Unsplash por fotografías autorizadas de la marca o por imágenes propias.
3. Enlaza los perfiles oficiales en la página de contacto cuando estén definidos.
4. El proyecto de referencia se presenta como propuesta académica, no como resultados comerciales comprobados.

Las fotografías externas y Google Fonts requieren conexión a internet.
